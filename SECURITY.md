# Security / 安全问题

The candidate is designed for authenticated Jupyter access or a token-protected standalone service on loopback. Treat its process as part of the account running Jupyter. File/decompression limits are not a sandbox for hostile inputs.

Once published, use **Security → Report a vulnerability** if the repository maintainer enables private vulnerability reporting. If unavailable, request a private contact through a public issue without posting exploit details, login URLs, tokens or private FITS files. Public issues are not confidential channels.

Maintained: the latest 0.1.4 release candidate. There is no long-term support branch. Include the affected version, platform, a minimal synthetic reproduction and the observed behavior in a report.

中文：候选版面向经过认证的 Jupyter 或回环地址上的独立服务。发布后优先使用仓库私密漏洞报告入口；没有入口时先请求私下联系方法，不在公开 issue 中放敏感内容。当前维护最新 0.1.4 候选版。
