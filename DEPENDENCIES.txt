FitsViewer 0.1.5rc1 - Full release - environment dependencies / 环境依赖清单
Repository / 仓库: https://github.com/minglinwang86/FitsViewer

This is an environment checklist, not a pip requirements file.
本文件用于检查完整环境。Python 运行依赖使用 requirements.txt，构建依赖使用 requirements-build.txt。

1. Prebuilt wheel runtime / 预编译 wheel 运行环境
   - GNU/Linux x86_64; glibc >= 2.28 and libgcc_s.so.1.
   - Python >= 3.10 with pip.
   - JupyterLab >= 4.4, < 5.
   - jupyter-server-proxy >= 4.4, < 5.
   - IPython >= 8 (Notebook embedding / Notebook 内嵌).
   - Browser with WebAssembly and WebGL / 浏览器支持 WebAssembly、WebGL.

   Python dependencies / Python 依赖安装:
     python -m pip install -r requirements.txt
   Install wheel[jupyter] for these integration dependencies; a plain wheel installs only FitsViewer.
   使用 wheel[jupyter] 安装集成依赖；普通 wheel 只安装 FitsViewer。
   Use the JupyterLab server's environment. A separate Notebook kernel needs the
   importable package for show(). / 服务与内核分属两个环境时，按 README 分别安装。

2. Optional Linux native window / 可选 Linux 原生窗口
   - X11, or Wayland with XWayland; usable OpenGL/GLX/EGL.
   - Typical Ubuntu 22.04 packages / Ubuntu 22.04 常用系统包:
       libx11-6 libx11-xcb1 libxcursor1 libxrandr2 libxi6
       libxkbcommon0 libxkbcommon-x11-0 libgl1 libegl1 libglx-mesa0
   - Other distributions may use different package names.
     其他发行版的系统包名可能不同；manylinux 标签并不保证显示驱动已配置。
   - Desktop default/Open With registration / 桌面默认关联与打开方式:
       xdg-utils shared-mime-info
       desktop-file-utils (optional cache refresh / 可选桌面缓存刷新)
   - X2Go requires a separately configured server/client and a working GLX session.
     X2Go 需自行配置服务端、客户端及显示能力；真实 X2Go 尚未验证。

3. Optional environment/remote tools / 可选环境与远程工具
   - Conda: needed only for --conda-env selection; --python/--prefix also accept venvs.
     选择 Conda 环境需可用的 conda 命令，或通过 --conda-exe 指定路径。
   - Python venv: Ubuntu may need python3-venv or the selected version's venv package.
     例如 Python 3.10 使用 python3.10-venv。
   - SSH access: OpenSSH client on the browser computer and an accessible SSH server.
     SSH 通道模式不需要 Linux 图形桌面；服务端无需安装浏览器。

4. Source/Git build / 源码与 Git 构建
   - Python >= 3.11 with venv (build environment / 构建环境).
     Runtime target Python may still be 3.10+ / 目标运行环境仍可使用 Python 3.10+。
   - Git, Bash, curl, C/C++ compiler, make, pkg-config.
   - Typical Ubuntu headers / Ubuntu 常用开发包:
       build-essential pkg-config python3-venv
       libxkbcommon-dev libxkbcommon-x11-dev libx11-dev
       libxrandr-dev libxi-dev libgl1-mesa-dev
   - Rust 1.99.1 with wasm32-unknown-unknown, rustfmt, clippy.
   - Node.js 24.22.0 and its bundled npm.
   - wasm-bindgen-cli 0.2.129 (must match Cargo.lock / 必须匹配锁文件).
   - cargo-zigbuild 0.23.4 and ziglang 0.13.0 for the glibc 2.28 build.
   - Python build tools: exact versions in requirements-build.txt.
   - Rust dependencies: Cargo.lock, including the small vendored fitsrs 0.4.1 patch.
     See vendor/README.fitsviewer.md. No CFITSIO, Astropy or plotting framework is
     needed at runtime for tiled FITS or basic spectra.
   - Shared Apache-2.0 Chinese fallback: web/fonts/cjk.ttf (common-character subset).
     Installed once as a shared native/browser asset. Its source/hash/license are
     recorded in web/fonts/font-manifest.json and licenses/fonts/droid/.
     Includes 3,755 GB2312 level-one Chinese characters plus punctuation/symbols.
     Optional regeneration uses fontTools; --charset full or --text-file extends
     coverage without adding a second font to the normal installation.
   - Frontend dependencies: jupyter/package-lock.json.
   - Bootstrap installs development tools under .tools/; see docs/BUILDING.md.
     bootstrap 将开发工具安装到项目 .tools/，不会替代所选的运行环境。
   - scripts/install.py --from-source skips optional QA browser downloads.
     Git 源码安装自动跳过测试浏览器；手动 bootstrap 可用 --no-qa 跳过。

5. Optional validation tools / 可选验证工具
   - Node Playwright 1.64.1 and Chromium: qa/package-lock.json.
     npm ci --prefix qa
     ./qa/node_modules/.bin/playwright install --with-deps chromium
   - Native desktop tests: Xvfb, xwininfo (x11-utils), GIO (libglib2.0-bin),
     desktop-file-validate (desktop-file-utils), xdg-utils, shared-mime-info.
   - Native screenshot script: Pillow (validated with 12.3.0).
   - Additional numerical scripts: NumPy and Astropy (available QA versions:
     NumPy 2.5.2, Astropy 8.0.1). These are optional validation dependencies.
   - Archived glibc loader checks: dpkg-deb (dpkg), xz support, network access.

6. Earlier platform validation / 历史平台验收
   These are earlier P0 checks; current Full evidence: docs/releases/VALIDATION-0.1.5rc1.md.
   以下为较早 P0 检查，当前 Full 验收见 docs/releases/VALIDATION-0.1.5rc1.md。
   - Ubuntu 22.04 x86_64 container; current wheel is manylinux_2_28_x86_64.
   - Python 3.10.12 + JupyterLab 4.4.0; Python 3.14.6 + JupyterLab 4.6.4.
   - glibc 2.28 and 2.31 isolated loader/backend checks, not full distribution tests.
   - Native window and desktop launcher with isolated Xvfb/software OpenGL.
   - Alpine/musl and ARM wheels, Safari and real X2Go forwarding remain unvalidated.
   - Wheel users do not need the source build or validation toolchains.
     安装预编译 wheel 无需源码构建或验证工具链。

7. Windows desktop and wheel / Windows 桌面与 wheel
   - Windows 10/11 x86_64 and usable OpenGL; ARM is not validated.
   - Desktop EXE / portable ZIP: Python, Conda and Jupyter are optional.
     独立桌面无需 Python、Conda 或 Jupyter，也无需服务端口。
   - Optional Jupyter integration: Python >=3.10; JupyterLab >=4.4,<5;
     jupyter-server-proxy >=4.4,<5; IPython >=8, as declared in requirements.txt.
   - JupyterLab 5.x is not validated and is excluded by current package ranges.
     5.x 尚未验证，当前安装约束暂未接纳；独立桌面不受此约束。
   - Native executable includes its Rust/MinGW runtime; DLL imports are Windows
     system libraries. No separately installed Rust or MinGW is required.
   - Windows build: x86_64-w64-mingw32-gcc (POSIX), binutils-mingw-w64-x86-64,
     Rust target x86_64-pc-windows-gnu, the web tools listed above.
   - Windows packaging: Python >=3.11 and Inno Setup 6.7.3 (compiler only).
     Icons are included; regenerating them with windows/make_icon.py needs Pillow.
   - Detailed setup and uninstall behavior: docs/WINDOWS.md.

8. On-demand scientific tools / 按需科学工具
   These packages stay in the selected existing Python/Conda environment; the
   viewer does not bundle or automatically install them. See docs/SCIENTIFIC_TOOLS.md.
   下列包由所选已有环境提供，不内嵌或自动安装。
   - NumPy + Astropy: J2000, WCS, catalogues, sky templates and SAMP.
   - SciPy: detection, local spherical XMatch, line profiles and Gaia fitting.
   - Specutils >=2,<3 + Astropy + SciPy + NumPy: optional PRO spectral candidates.
     requirements-spectra.txt is an opt-in install list, never a viewer dependency.
   - NumPy + SciPy: optional spectral continuum, EW/pEW, smoothing and bounded
     Gaussian/Voigt profiles. Coordinate/display overlays and relative blackbody
     references use the existing viewer; no additional scientific runtime is bundled.
   - scikit-image: probabilistic Hough straight-line detection.
   - Shapely: sky transformation of finite-width line/curve apertures.
   - Matplotlib: PNG/JPG/PDF/SVG figures, RGB previews and MathText subset.
     text.usetex is disabled; no TeX engine is embedded.
   - PyVO: SIA v1, SSA, TAP and ESA Gaia reference queries.
   - Astroquery: CDS XMatch. Astroalign: optional Gaia field pattern fallback.
   - Select with --python /path/to/env/bin/python or FITSVIEWER_PYTHON.
     Jupyter defaults to its server environment; a separate kernel is independent.

9. macOS portable desktop / macOS 便携桌面
   - Separate native arm64 (Apple Silicon) and x86_64 (Intel) ZIP files.
   - Automated acceptance runs on macOS 15. The compile target is 11.0;
     older macOS releases and complete GUI interaction are not certified.
   - No Python needed for basic viewing. Scientific Python remains external.
   - Ad-hoc signature; no Developer ID or Apple notarization. See docs/MACOS.md.
   - No Mac Python wheel/Jupyter installer or Finder association in this release.
   - Build: macOS, Xcode Command Line Tools, Python 3.11+, Rust 1.99.1;
     reviewed Full web/Lab resources are SHA256-locked in config/macos-full-assets.json.
   - Test-only NumPy/Astropy are not copied into the application.
