# FitsViewer 0.1.5rc1 — Full

One full distribution with Minimal and PRO interfaces, native Linux/Windows/macOS
windows, a remote browser viewer, JupyterLab double-click opening and Notebook
embedding. This is a prerelease for inspection and feedback.

一个全功能发行包，包含极简／PRO、Linux／Windows／macOS 原生窗口、远程浏览器、JupyterLab
双击打开和 Notebook 内嵌。这是用于试用与反馈的预发布版。

> **Scientific use / 科学使用说明：** Coordinates, fluxes, magnitudes and other
> identified, derived or measured results are recommended for inspection and reference
> only, not for direct use as scientific measurements in papers. Independently validate,
> calibrate and assess uncertainties/systematics before publication.
>
> 本工具识别、推算或测量的坐标、流量、星等等结果建议仅作为检查与参考，不应直接作为
> 论文中的科学测量数据；科研发表前需独立验证、校准并评估不确定度与系统误差。

## Minimal first / 极简模式

- FITS/gzip and supported tiled `.fz` images, basic FITS/text spectra.
- Auto display, eight DS9-style stretches, zoom/pan and right-drag brightness/contrast.
- Editable circular apertures with sky annuli; move, resize, select and Delete.
- Shared pixel/J2000 coordinates and external Gaia field recognition/calibration.
- English/简体中文, Unicode paths, compact controls and remembered popup geometry.

极简模式包含图像／基础光谱、自动显示、八种拉伸、缩放与右键亮度／对比度、可编辑及
删除的圆孔径与背景环、J2000／Gaia 坐标、中英文与中文路径支持。

## Linux/Jupyter installation / Linux 与 Jupyter 安装

Activate the environment running Jupyter, then install the downloaded wheel:

```bash
python -m pip install --upgrade "./fitsviewer-0.1.5rc1-py3-none-manylinux_2_28_x86_64.whl[jupyter]"
fitsviewer defaults set --jupyter yes --desktop no
fitsviewer jupyter start --root "$HOME/data" --port 8082
```

Use an existing data directory. Restart an already running Jupyter server and
refresh the browser. `[jupyter]` adds integration dependencies; a plain wheel
installs FitsViewer only. Existing science packages remain in their own environment.

数据目录须存在。重启已有 Jupyter 服务并刷新浏览器。`[jupyter]` 安装集成依赖；
普通 wheel 只安装 FitsViewer。不要只装到另一个 Notebook 内核环境。

For remote access, run on your local computer / 远程访问时在本地执行：

```bash
ssh -N -L 127.0.0.1:18082:127.0.0.1:8082 user@server.example.com
```

Open the printed Jupyter login URL using local port 18082. Keep the token private.
See [installation, Conda and SSH instructions](https://github.com/minglinwang86/FitsViewer/blob/v0.1.5-rc.1/docs/INSTALL.md).

## Windows installation / Windows 安装

Run Setup for a per-user native installation, or extract the portable ZIP.
Python is optional for desktop use. Setup offers an existing Python/Conda target
and an independent default FITS viewer choice. Enable Jupyter dependency installation
if integration packages are missing. Windows may require a Default Apps confirmation.

Setup 为当前用户安装，portable 解压即用。桌面无需 Python；安装器可选 Python/Conda
关联及默认 FITS 查看器。缺少集成依赖时允许安装 Jupyter 依赖；系统可能要求在默认应用中确认。

For Windows Jupyter / Windows 的 Jupyter 环境：

```powershell
python -m pip install --upgrade ".\fitsviewer-0.1.5rc1-py3-none-win_amd64.whl[jupyter]"
fitsviewer defaults set --jupyter yes --desktop no
```

## macOS installation / macOS 安装

Choose the ZIP for Apple Silicon (`arm64`) or Intel (`x86_64`), extract it and open
`FitsViewer.app`. Use the app's Open button or the included `./fitsviewer` terminal
launcher to choose a FITS image or spectrum. Optional scientific tools use an
existing Python/Conda environment selected with `--python`.

按处理器选择 ZIP，解压后打开 `FitsViewer.app`。通过程序的“打开”或附带的终端入口
`./fitsviewer` 选择图像／光谱；科学工具通过 `--python` 调用已有环境。

The app is ad-hoc signed, without Apple notarization. It does not register Finder
file associations or install a Mac Jupyter extension. See the
[macOS first-launch guide](https://github.com/minglinwang86/FitsViewer/blob/v0.1.5-rc.1/docs/MACOS.md).

采用临时签名、未经 Apple 公证；不修改 Finder 文件关联，也不安装 Mac 本机 Jupyter
扩展。首次启动方式见上述 Mac 指南；Mac 浏览器可继续访问 Linux Jupyter。

## Requirements and scientific scope / 要求与边界

- Linux x86_64 glibc 2.28+; Windows 10/11 x86_64. Native windows need usable OpenGL.
- macOS arm64/x86_64 portable apps are tested on macOS 15; older versions and complete interactive Mac workflows are not certified.
- Python 3.10+ for integration; JupyterLab `>=4.4,<5`. Linux/Windows ARM, Linux musl, Safari and real X2Go forwarding are not certified.
- RICE/GZIP/GZIP2 tiled images are supported; HCOMPRESS/PLIO, cubes and general FITS-table editing are not.
- Extract ZIP/TAR archives first. Multi-spectrum display is supported; coaddition and spectrum-to-spectrum subtraction are not.
- Gaia uses a bounded initial field; relative layer brightness is not absolute photometric calibration.
- Candidate lines, fitted components and blackbody references require scientific interpretation.
