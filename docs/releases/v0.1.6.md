# FitsViewer 0.1.6 Full

One Full package includes **Minimal** and **PRO**, native desktop viewing,
Jupyter integration and the independent SSH viewer. Scientific calculations call
an external selected Python environment. No Chromium, Python scientific stack,
catalogue index, science data or TeX is bundled.

## Minimal first

- Compact English/Chinese controls, separate Settings/Header windows and remembered
  panel geometry. The path field leaves the primary file actions accessible.
- Auto display, HDU/header, stretch/limits, histogram, pixel/sky readout and basic
  image/spectrum viewing.
- Editable apertures, selected Delete/Backspace and clear all; display rotation
  with left/right 90°, arbitrary angle and a directly visible Reset button.
- Adjustable scale bar beside HDU. Coordinates and overlays use original pixels.
- Gaia field calibration defaults to a 3″ independent-validation limit and handles
  legacy FITS observation dates such as `29/11/51` correctly.

## PRO by task

- Horizontal task buttons and dedicated pages with visible primary actions;
  detailed diagnostics and advanced parameters are available under `…`.
- Image/spectrum layers, relative field-star brightness matching, catalogue
  identities separated from local intensity candidates, manual seeds/paths and
  explicit data/error provenance.
- CDS presets and bounded nearby archive queries with coverage/product/DataLink
  semantics. Final download/footprint details are included in the illustrated
  [user guide](../../README.md).
- Spectrum references and external emission/absorption candidates; continuum,
  EW/pEW, net flux, smoothing and bounded Gaussian/Voigt fits. Air/vacuum rest
  metrics now match the display's conversion order.
- External environment inspection and opt-in missing-dependency installation;
  installation progress/results survive unrelated View releases.

## Ordinary SSH and large images

`fver image.fits` provides a first clickable independent browser URL and reuses
open views for later commands. A paired optional local helper can open the native
app. SSH local forwarding is configured explicitly; Jupyter and X11 are not
prerequisites. [Commands, setup and capability boundaries](../REMOTE_VIEWING.md).

Complete decoded packets up to 20 MB transfer once. Larger supported images use
bounded numeric previews and tiles, with separate original-pixel requests and
scientific operations on original files. Closing cancels owned transfers/jobs.

## Downloads and validation

Platform results and their limits are recorded in the linked validation record.
Use the release's `SHA256SUMS` to check the selected download.

Choose the Linux or Windows wheel for an existing Python/Jupyter environment,
Windows Setup/portable ZIP for desktop use, or the macOS ZIP matching Apple
Silicon/Intel. The source archive is for developers, not a pip sdist.
See [installation](../INSTALL.md), [validation and limits](VALIDATION-0.1.6.md),
[architecture](../ARCHITECTURE.md) and [AgentWorkLog](../../AgentWorkLog.md).

**Scientific use:** Identified or derived coordinates, fluxes, magnitudes and
other values are intended for inspection/reference. Independently validate,
calibrate and assess uncertainty/systematics before using them in a paper.
