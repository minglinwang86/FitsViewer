# FitsViewer 0.1.4rc2

FitsViewer now uses one name across the Python package, import, CLI, desktop window and Jupyter extension: `fitsviewer`. No compatibility aliases are installed.

FitsViewer 统一使用一个名称：Python 包、导入、命令与 Jupyter 扩展均为 `fitsviewer`，不安装旧别名。

```python
from fitsviewer import show
show('image.fits')
```

```bash
fitsviewer image.fits
fitsviewer --native image.fits
fitsviewer status
```

The Windows Setup EXE provides optional existing Python/Conda environment selection and independent FITS default-viewer choices. The native desktop needs no Python. The EXE includes an embedded icon and version information. A portable ZIP is also available.

Windows 安装器提供可选的 Python/Conda 环境选择和独立的默认 FITS 查看器选项。独立桌面无需 Python；EXE 内嵌图标与版本信息，另提供免安装 ZIP。

Linux x86_64 uses a glibc 2.28 baseline. Jupyter integration requires Python 3.10+ and JupyterLab `>=4.4,<5`; 5.x has not been validated. See [Windows setup](https://github.com/minglinwang86/FitsViewer/blob/v0.1.4-rc.2/docs/WINDOWS.md), [dependencies](https://github.com/minglinwang86/FitsViewer/blob/v0.1.4-rc.2/DEPENDENCIES.txt) and the [validation record](https://github.com/minglinwang86/FitsViewer/blob/v0.1.4-rc.2/docs/releases/VALIDATION-0.1.4rc2.md).

Download the wheel matching the operating system. This project is distributed through GitHub Releases and is not yet published on PyPI. Use `python -m pip install /path/to/downloaded.whl`.

When upgrading from the earlier rc1, remove that distribution from the same environment before installing the renamed package:

```bash
python -m pip uninstall fitsview-jupyter
```

That is the historical distribution name, not an alias installed by rc2. Existing Jupyter services must be restarted from the selected environment after installation. Windows may require the user's confirmation in Default apps when a protected file association already exists. Close native windows before uninstalling. Native binaries are unsigned; Windows ARM, macOS native binaries and real X2Go forwarding remain outside this validation.

旧 rc1 的包名只用于升级清理；rc2 不提供旧名称入口。安装后从所选环境重启 JupyterLab。受 Windows 保护的默认文件关联需由用户在系统设置中确认；卸载前关闭原生窗口。
