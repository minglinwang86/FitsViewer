# FitsViewer 0.1.4rc2 — Linux and Windows

轻量 FITS 查看器，支持 JupyterLab 文件列表双击、Notebook 内嵌、SSH 浏览器访问及原生桌面窗口。支持缩放、Linear/Log/Sqrt/Asinh scale 和右键拖动调整亮度/对比度。包名、导入和命令统一为 `fitsviewer`。

A lightweight FITS viewer for JupyterLab, notebooks, remote browsers and native desktops. Install a prebuilt wheel to use it without Rust, Node.js or source compilation. Distribution through GitHub Releases; this project is not yet published on PyPI.

## Linux：直接安装 / Install the Linux wheel

先激活**实际启动 JupyterLab 的 Python/Conda 环境**，再执行以下命令。pip 会安装该 wheel 及所需的 Python 依赖。

Activate the environment that runs the JupyterLab server, then install:

```bash
python -m pip install --upgrade "https://github.com/minglinwang86/FitsViewer/releases/download/v0.1.4-rc.2/fitsviewer-0.1.4rc2-py3-none-manylinux_2_28_x86_64.whl"
fitsviewer defaults set --jupyter yes --desktop no
```

在新建的数据目录启动服务；也可将 `$HOME/data` 替换成已有目录：

```bash
mkdir -p "$HOME/data"
fitsviewer jupyter start --root "$HOME/data" --port 8082 --browser-port 18082
```

若安装前已有 JupyterLab 正在运行，先保存 Notebook，再从安装环境重启该服务并刷新浏览器。安装不会自动重启服务；`jupyter start` 可能复用已运行的服务。之后双击 `.fits`、`.fit`、`.fts` 或对应的 gzip FITS 即可打开。

Save your work and restart an existing JupyterLab server from the installation environment after installation. The start command may reuse an existing service. Refresh the browser, then double-click a FITS file.

## 选择 Python / Conda 环境 / Select an environment

直接使用目标 Python 的 pip，或先激活已有 Conda 环境。将 `astro` 替换成你的环境名：

```bash
conda activate astro
python -m pip install --upgrade "https://github.com/minglinwang86/FitsViewer/releases/download/v0.1.4-rc.2/fitsviewer-0.1.4rc2-py3-none-manylinux_2_28_x86_64.whl"
fitsviewer defaults set --jupyter yes --desktop no
```

已有完整 FitsViewer 安装时，可复制到另一个环境；以下两种目标选择任选一种。`--with-jupyter` 允许在目标缺少受支持的 JupyterLab 时安装它：

Once FitsViewer is installed, use one of these commands to install it into another environment:

```bash
fitsviewer install --python /path/to/env/bin/python --with-jupyter --default-viewer yes --desktop-default no
fitsviewer install --conda-env astro --with-jupyter --default-viewer yes --desktop-default no
```

## SSH 连接 / Connect from Windows, macOS or Linux

Linux 服务器执行上面的 `jupyter start` 后，在**浏览器所在电脑**运行以下命令，将用户名、服务器地址和 SSH 端口替换为实际值：

After starting the Linux service, run this on the computer with your browser:

```bash
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:18082:127.0.0.1:8082 -p 22 user@server.example.com
```

保持 SSH 终端运行，打开 [JupyterLab（本机 18082）](http://127.0.0.1:18082/lab)，或使用服务启动时打印的登录链接；认证信息沿用你的 Jupyter 配置。映射为：本机 `18082` → Linux Jupyter `8082`。Rust 内部代理端口自动分配，无需另建通道。

Keep the SSH connection open and use the printed login link or the local JupyterLab link above. Authentication follows your Jupyter configuration. Only the Jupyter port needs forwarding.

查看端口，或保存下次启动的端口配置：

```bash
fitsviewer ports
fitsviewer ports set --jupyter 8084 --browser 18084
```

端口修改用于后续启动；已运行的服务和 SSH 通道需分别重新启动或重新建立。

## Windows 桌面与 Jupyter / Windows desktop and Jupyter

普通桌面使用：下载并运行上方 **Setup 安装器**，或解压 **Portable ZIP** 后运行 `fitsviewer.exe`。独立桌面无需 Python。安装器可选已有 Python/Conda 环境以关联 Jupyter，并可选择默认 FITS 查看器；受系统保护的默认文件关联可能需要在 Windows 默认应用设置中确认。

For desktop use, run Setup or extract the portable ZIP and launch `fitsviewer.exe`. Setup offers optional Python/Conda integration and a default FITS viewer choice.

只需在已有 Windows Python/Conda 环境中绑定 Jupyter 时，激活该环境，再在 PowerShell 或终端执行：

For Jupyter integration in an activated Windows Python/Conda environment:

```powershell
python -m pip install --upgrade "https://github.com/minglinwang86/FitsViewer/releases/download/v0.1.4-rc.2/fitsviewer-0.1.4rc2-py3-none-win_amd64.whl"
fitsviewer defaults set --jupyter yes --desktop no
```

重启该环境中的 JupyterLab 后，文件列表双击即可打开。Windows 原生程序包含图标和版本信息，发行二进制尚未签名。

## Notebook 和 Linux 桌面 / Notebook and native Linux

```python
from fitsviewer import show
show("image.fits", height=650)
```

路径相对于 Jupyter 文件根目录。若 Notebook 内核与服务使用不同环境，内核环境也需安装包以导入 `fitsviewer`；仅在内核中安装不会为另一个环境的 JupyterLab 服务注册扩展。

Paths are relative to the Jupyter server root. A separate notebook kernel environment also needs the package to import `fitsviewer`.

Linux 命令行与可选原生桌面窗口：

```bash
fitsviewer image.fits
fitsviewer --native image.fits
```

`--native` 需要可用的 X11/OpenGL 显示环境。Linux 桌面需要默认 FITS 文件关联时使用 `fitsviewer defaults set --desktop yes`；取消关联使用 `fitsviewer defaults set --desktop no`。

## 绑定检查 / Check Jupyter integration

```bash
jupyter server extension list
jupyter labextension list
```

应启用后端 `fitsviewer`、`jupyter_server_proxy` 和前端 `fitsviewer`。需要重新启用时，在目标环境执行以下命令，再重启 JupyterLab：

```bash
python -m jupyter server extension enable --py fitsviewer --sys-prefix
python -m jupyter server extension enable --py jupyter_server_proxy --sys-prefix
python -m jupyter labextension enable fitsviewer fitsviewer:viewer --level=sys_prefix
```
