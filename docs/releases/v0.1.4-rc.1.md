# FITSView 0.1.4rc1 — prerelease / 预发布候选版

Release candidate prepared 2026-10-17. Download platform-specific assets from GitHub Releases.

FITSView uses Rust/fitsrs to provide read-only 2D FITS viewing in JupyterLab, a browser reached through SSH, an optional native Linux window and Notebook IFrames. The Python package is `fitsview-jupyter`, a separate project from the existing `fitsview` package.

## Included / 包含功能

- JupyterLab double-click opening and the `show()` Notebook interface.
- Zoom/pan; Linear/Log/Sqrt/Asinh; ZScale/percentile/minmax/manual limits.
- DS9-style right-drag brightness/contrast; HDU/header and raw/physical pixel readouts.
- Port/status/tunnel/Jupyter commands and selected-environment installation with English binding diagnostics.
- Terminal Python/Conda selection, Jupyter default-viewer switch and user-level Linux desktop registration.
- English/Chinese guides, MIT source license, dependency/font notices and candidate release tooling.

## Install / 安装

Linux x86_64, glibc>=2.28, Python>=3.10, JupyterLab>=4.4,<5:

```bash
python -m pip install --upgrade ./fitsview_jupyter-0.1.4rc1-py3-none-manylinux_2_28_x86_64.whl
```

Restart the JupyterLab server from the installation environment and refresh the browser. Refer to the English/Chinese README for SSH and Notebook use.

## Validation boundaries / 验证范围

Release preparation requires strict wheel metadata, isolated installation/binding/uninstall and browser/Notebook regression checks. The per-candidate validation report records actual completed checks; a CI definition alone does not imply a hosted run passed. Historical MVP reports are not substituted for the candidate's checks.

The current wheel targets GNU/Linux x86_64 systems with glibc>=2.28; Alpine/musl and ARM need separate builds and validation. Mac/Windows browser clients can use SSH; Safari and actual X2Go/X11 forwarding remain unvalidated. Native desktop launch is checked with an isolated Xvfb display, not a real X2Go session. Tile-compressed `.fz`, cubes, tables, WCS, regions and photometry are outside this candidate. Large images are bounded by 512MiB/32Mi pixels and currently load in full.
