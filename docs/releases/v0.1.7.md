## Minimal / 极简模式

- Histogram windows keep their position and size across hidden Jupyter tabs and reopening. Log counts remembers the chosen state; initial content is fully expanded.
- The compact histogram has a roughly 16:9 default frame, with Log counts beside
  its title and statistics in `...`. Drag the frame to resize the window and plot.
- Click or drag the physical histogram's Low/High markers, or enter exact limits.
  This changes display brightness without rewriting original pixels.
- Open later images in the same native window using the saved preference.
  **Exit all** gracefully closes registered same-user FitsViewer native windows.
- Within the same viewer, choose **New tab** or **Replace current**; tabs retain
  their own HDU, view and measurements. The Minimal and PRO choices are saved separately.
- Document tabs sit immediately below the toolbars. View/Measure/Coordinates
  keep a stable height; rapid task switching no longer accidentally folds the toolbar.
- Large images use bounded tiles and caches. Minimal may use 16-bit display tiles;
  exact pixel readouts and science still use original values. PRO retains original
  precision for its image transport.
- Six interface languages: English, Simplified Chinese, Italian, Spanish, German,
  and French, stored in a shared, maintainable locale directory.

可直接拖动直方图上下限或填写精确数值；新增同窗口打开偏好和“退出全部窗口”。
直方图默认框接近 16:9，对数计数位于标题旁，统计信息收进“…”；窗口及绘图区可调整大小。
同窗打开可选“新选项卡”或“覆盖当前”，各选项卡保留 HDU、视野和测量，极简/PRO 分别记忆偏好。
标签栏位于工具栏下、图像上；切换查看、测量、坐标时高度保持稳定，快速切换不再误折叠。
大图采用有界图块与缓存；极简的显示压缩不会改动原始文件、精确像素读数和科学计算，
PRO 图像保持原始精度。中、英、意、西、德、法六种界面语言同步。

## PRO and integrations / PRO 与集成

- PRO also offers **New layer**, preserving the current reference image. Opening
  downloaded observations uses the selected destination. Document tabs and comparison
  layers are separate controls; single-source remote views remain restricted.
- PRO places document tabs and the existing file/session controls on one shared
  row, with the controls aligned to the right.
- Photometry puts flux, units, uncertainty and result copying before detailed
  geometry. Aperture selection, resize, Delete and clearing remain available.
- Spectral tasks show primary metrics and validity failures first, keep warnings
  expandable, and remember scroll positions separately for each task.
- Python manual star selection supports image coordinates, completion/cancellation
  and subsequent requests in the same browser through the generic Python client.
  See [manual selection](https://github.com/minglinwang86/FitsViewer/blob/v0.1.7/docs/MANUAL_STAR_SELECTION.md).
- Jupyter uses a private backend header credential, kept out of viewer URLs.
  Window IPC and download cancellation/commit handling have been hardened.
- SSH uses the existing `fver` viewer and optional local helper. A plain remote
  shell still needs its forwarded URL opened on the client; native XPA emulation
  and a native manual-selection IPC interface are not included.

测光优先显示流量、单位和误差；光谱各任务分开保存滚动位置，主要指标和有效性问题
更容易看到。增加通用 Python 手动选星接口，科学处理保持在外部调用方环境中。
PRO 还可选择“新图层”，保留当前参考图；下载的观测图像也遵循所选打开方式。
PRO 的标签与原文件/会话操作共用一行，操作按钮位于右侧。
修复窗口通信、下载取消与保存竞争，以及 Jupyter 后端认证等问题。普通 SSH 仍需
在本机打开转发 URL，或使用可选助手。

## Validation and limits / 验证与限制

Linux functional/science/UI results are recorded in
[the validation log](https://github.com/minglinwang86/FitsViewer/blob/v0.1.7/docs/releases/VALIDATION-0.1.7.md).
Unchanged accepted tests are reused; the platform workflow adds Windows/macOS
native builds, Unicode paths, packaging, server/worker and shutdown checks.
CI evidence shipped with this release identifies the exact source and resource hashes.

Mac packages use an **ad-hoc signature**, without Developer ID or Apple notarization.
macOS 15 is the CI test system; an 11.0 deployment target is not proof that every
older macOS release was tested. Native GUI startup/texture checks do not constitute
manual acceptance of every Mac workflow. Windows CI uses a separately downloaded,
hash-pinned Mesa software renderer for its isolated GUI tests; Mesa is not shipped.
External catalogue availability and calibration quality remain data/service dependent.

Mac 使用临时签名，未经 Apple 公证；CI 在 macOS 15 检查，旧系统未逐一验证。
Windows CI 的软件渲染器只用于测试，不包含在发行包中。外部星表可用性和坐标定标
质量仍取决于网络、服务和数据。原始报错的某个模板文件未取得，不能声称已逐字节复现。

**Coordinates, fluxes, magnitudes and other values produced by this tool are
recommended for reference only, not as scientific data in a paper without an
independently validated reduction and uncertainty assessment.**

**本工具识别或计算的坐标、流量、星等等数值建议仅作为参考；未经独立校验的
数据处理和误差评估，不应直接作为论文中的科学数据。**
